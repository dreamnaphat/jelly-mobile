# Spec: ระบบแปลภาษาเสียง ไทย ↔ จีน (jelly-mobile)

> เอกสารนี้บอกว่า **ระบบต้องเป็นอย่างไร** ส่วนลำดับงานและระยะเวลาอยู่ใน [PLAN.md](PLAN.md)
> สถานะ: ร่าง · อัปเดต 27 ก.ย. 2026 · ตัวเลขเวลาเป็นค่าประมาณ ต้องยืนยันใน Phase 0

## 1. เป้าหมาย

แอปมือถือสำหรับให้คนไทยกับคนจีนคุยกันต่อหน้า โดยแปลเสียงเป็นเสียงทั้งสองทาง

## 2. ความต้องการ

### 2.1 ความต้องการด้านการทำงาน

| รหัส | ความต้องการ |
|---|---|
| F1 | พูดภาษาจีน → แสดงคำแปลภาษาไทย และพูดออกเป็นเสียงภาษาไทย |
| F2 | พูดภาษาไทย → แสดงคำแปลภาษาจีน และพูดออกเป็นเสียงภาษาจีน |
| F3 | มีปุ่มกดพูดแยก 2 ภาษา ("พูดไทย" / "说中文") |
| F4 | แสดงข้อความที่ถอดได้แบบสดระหว่างพูด และแสดงทั้งต้นฉบับและคำแปล |
| F5 | มีหน้าจอสำหรับนั่งหันหน้าคุยกัน โดยครึ่งบนหมุนกลับหัวให้อีกฝ่ายอ่าน |
| F6 | มีประวัติการสนทนา ปุ่มเล่นเสียงซ้ำ และแก้ข้อความแล้วแปลใหม่ได้ |
| F7 | ตั้งค่าได้: คำลงท้ายครับ/ค่ะ, จีนตัวย่อ/ตัวเต็ม, รายการคำเฉพาะ |
| F8 | ใช้งานได้แม้ไม่มีอินเทอร์เน็ต (โหมดสำรอง ความเร็วลดลงได้) |

### 2.2 ความต้องการด้านคุณภาพ

| รหัส | ความต้องการ | เกณฑ์วัด |
|---|---|---|
| N1 | ไม่มีค่าใช้จ่ายในการใช้งาน | ใช้เฉพาะของฟรี: โมเดลโอเพนซอร์ส และคลาวด์ระดับฟรีที่ไม่มีวันคิดเงิน |
| N2 | เร็วที่สุด | เวลานับจากปล่อยปุ่มพูดจนเสียงคำแปลเริ่มดัง: **p50 ≤ 1.0 วิ, p90 ≤ 1.5 วิ** บน 4G ในไทย |
| N3 | ความเป็นส่วนตัว | เสียงของผู้ใช้ไม่ออกจากเครื่อง ส่งขึ้นคลาวด์เฉพาะข้อความ |
| N4 | คุณภาพคำแปล | ≥ 90% ของประโยคทดสอบ ผู้รู้สองภาษาบอกว่าความหมายถูก |
| N5 | รองรับหลายระบบ | Android ทั่วไป, Huawei EMUI, Huawei HarmonyOS 5/6 |

## 3. ข้อจำกัดที่ต้องรู้

- **Huawei ที่ขายในไทยใช้ EMUI** (มี Android เป็นฐาน ไม่มี Google services) ติดตั้ง APK ได้
- **Huawei เครื่องตลาดจีนใช้ HarmonyOS 5/6** ติดตั้ง APK ไม่ได้ ต้องเขียนแอปด้วย ArkTS
  - Huawei ประกาศ (ส.ค. 2026) ว่าจะนำร่อง HarmonyOS นอกจีน โดยมีเอเชียตะวันออกเฉียงใต้อยู่ในกลุ่มแรก
- **เครื่องมือเสียงของ Huawei ไม่รองรับภาษาไทยครบ**
  - HMS ML Kit: การฟังต้องต่อเน็ต (รองรับไทย) ส่วนการพูดไม่มีภาษาไทย
  - Core Speech Kit (HarmonyOS): ฟังและพูดได้แบบออฟไลน์ แต่เฉพาะภาษาจีน
- **การแปลในเครื่องช้า** (1–4 วิบนมือถือ) จึงไม่ผ่าน N2 ต้องใช้คลาวด์เป็นหลัก
- **แอปห้ามพึ่ง Google services** เพราะ Huawei ไม่มี

## 4. สถาปัตยกรรม

### 4.1 ส่วนประกอบ

| ขั้นตอน | รันที่ไหน | Android / EMUI | HarmonyOS 5/6 |
|---|---|---|---|
| ฟังภาษาไทย | ในเครื่อง | Typhoon ASR Real-time ผ่าน sherpa-onnx | เหมือนกัน |
| ฟังภาษาจีน | ในเครื่อง | sherpa-onnx (streaming zipformer/paraformer) | Core Speech Kit |
| แปลไทย↔จีน | คลาวด์ | Azure Translator ระดับ F0 | เหมือนกัน |
| พูดภาษาจีน | ในเครื่อง | sherpa-onnx (หรือ HMS ML Kit TTS แบบออฟไลน์) | Core Speech Kit |
| พูดภาษาไทย | คลาวด์ | Azure Neural TTS ระดับ F0 | เหมือนกัน |
| ตัวกลางเก็บ API key | คลาวด์ | Cloudflare Workers แบบฟรี | เหมือนกัน |

### 4.2 ลำดับการทำงานต่อหนึ่งประโยค

1. ผู้ใช้กดปุ่มภาษาค้างไว้ แอปถอดเสียงในเครื่องและแสดงข้อความสด
2. ปล่อยปุ่ม ได้ข้อความสุดท้าย แล้วส่งข้อความไปแปลผ่านตัวกลาง
3. ได้คำแปล แสดงบนจอ แล้วสร้างเสียง (จีน: ในเครื่อง / ไทย: คลาวด์)
4. เล่นเสียงทันทีที่ได้ท่อนแรก ระหว่างเล่นเสียงให้ปิดไมค์

### 4.3 โหมดสำรอง

เมื่อไม่มีเน็ต หรือโควตาฟรีหมด แอปต้องสลับเองโดยอัตโนมัติ:
- แปล: HY-MT1.5-1.8B ในเครื่อง ผ่าน llama.cpp
- พูดภาษาไทย: MMS-TTS Thai ในเครื่อง
- ความเร็วที่ยอมรับได้ในโหมดนี้: ~1.5–4 วินาที

### 4.4 โควตาฟรีของคลาวด์

| บริการ | โควตาฟรีต่อเดือน | พอสำหรับ |
|---|---|---|
| Azure Translator F0 | 2 ล้านตัวอักษร | คุยได้ ~100–200 ชั่วโมง |
| Azure Speech F0 (TTS) | 5 แสนตัวอักษร | คุยได้ ~35–70 ชั่วโมง (**โควตาที่หมดก่อน**) |
| Azure Speech F0 (STT) | 5 ชั่วโมงเสียง | สำรองไว้เป็นโหมดแม่นยำสูง |

ที่มาของตัวเลข: Azure นับทุก Unicode code point เป็น 1 ตัวอักษร ภาษาไทยพูดต่อเนื่องได้ราว 15 ตัวอักษร/วินาที (วรรณยุกต์และสระนับแยก) ภาษาจีนราว 5 ตัวอักษร/วินาที คุยจริงมีคนพูดราว 25–50% ของเวลา → ใช้ราว 9,000–18,000 ตัวอักษร/ชม. ส่วนเสียงไทยใช้ราว 7,000–14,000 ตัวอักษร/ชม. (เฉพาะคำแปลจากจีนเป็นไทย) เมื่อโควตาเสียงไทยหมด แอปใช้ MMS-TTS Thai ในเครื่องแทน

ระดับฟรี (F0) ไม่มีวันคิดเงิน ถ้าใช้ครบโควตา บริการจะหยุดตอบเท่านั้น และให้ใช้ region Southeast Asia

## 5. งบเวลา (หลังปล่อยปุ่มพูด)

| ขั้นตอน | เวลาโดยประมาณ |
|---|---|
| ได้ข้อความสุดท้าย | 0.1–0.3 วิ |
| แปลบนคลาวด์ รวมเวลาเน็ต | 0.2–0.4 วิ |
| เสียงเริ่มดัง: จีนในเครื่อง / ไทยบนคลาวด์ | 0.1–0.4 วิ |
| **รวม** | **~0.5–1.1 วิ** |

เทคนิคที่ต้องใช้:
- ใช้ปุ่มกดพูด ไม่ต้องรอให้ผู้พูดเงียบ
- โหลดโมเดลไว้ตั้งแต่เปิดแอป และเปิดการเชื่อมต่อไปคลาวด์ค้างไว้
- เริ่มเล่นเสียงทันทีที่ได้ท่อนแรกของคำแปล

## 6. แอป

| แอป | ระบบที่รองรับ | เทคโนโลยี |
|---|---|---|
| แอป Android | Android ทั่วไป + Huawei EMUI | Kotlin + Jetpack Compose, sherpa-onnx, llama.cpp |
| แอป HarmonyOS | Huawei HarmonyOS 5/6 | ArkTS + ArkUI, sherpa-onnx, Core Speech Kit |

ทั้งสองแอปใช้โมเดลชุดเดียวกันและตัวกลางบนคลาวด์ตัวเดียวกัน เครื่องทดสอบหลักของแอป HarmonyOS คือ Huawei Mate 80 Pro (HarmonyOS 6) โหมดออฟไลน์บน HarmonyOS ทำทีหลัง เพราะ llama.cpp ยังไม่มีเวอร์ชันทางการ

## 7. สเปกมือถือ

| ระดับ | สเปก | ได้อะไร |
|---|---|---|
| ขั้นต่ำ | ชิประดับกลาง (Snapdragon 7 series / Dimensity 7000–8000 / Kirin 8000 series) · RAM 8 GB · ความจุ 128 GB | ผ่าน N2 เมื่อมีเน็ต แต่โหมดออฟไลน์ช้า |
| แนะนำ | ชิประดับท็อป (Snapdragon 8 Elite / Dimensity 9400 / Kirin 9 series) · RAM 12 GB · ความจุ 256 GB | เร็วที่สุด และโหมดออฟไลน์ใช้ได้จริง (~1.5–3 วิ) |

รุ่นที่แนะนำในงบเครื่องละ 40,000 บาท อยู่ใน PLAN ข้อ 4

โมเดลในเครื่องรวมราว 0.3–0.6 GB และถ้ารวมโมเดลแปลสำรองจะเป็น ~1.5 GB ให้ดาวน์โหลดตอนเปิดแอปครั้งแรก ไม่ใส่ไว้ใน APK
